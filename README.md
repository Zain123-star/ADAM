# AMDM: Adaptive Multi-dimensional Model

Official PyTorch implementation for the paper: **"Reconstructing Unseen Transitions: An Adaptive Multi-Dimensional Model for Origin-Aware Next Destination Prediction"**.

## Abstract
AMDM addresses the **transition sparsity** problem in next-destination prediction, where a test origin-destination (OD) pair is unobserved in training data even though both endpoints are well known. Our model introduces a **Multi-Hop Transition Reconstruction** mechanism to supply evidence for unseen transitions.
